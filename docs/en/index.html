Persian text in AI chats, right-to-left and readable

AI chat platforms show Persian answers left-to-right. GeekRTL is a Chrome extension that fixes the direction, alignment and font of every Persian and Arabic message, automatically.

Details

Small and out of the way

  • Automatic detection

    A message that is mostly Persian or Arabic becomes right-to-left; mixed text takes its direction from the text itself. Answers are followed while they are still being written.

  • Code left as is

    Code blocks and commands always stay left-to-right, so they read and copy correctly.

  • The prompt box

    The box you type in switches direction as you type: Persian right-to-left, English left-to-right.

  • No data sent

    Nothing leaves your browser. Fonts ship with the extension, and it needs only two permissions: saving your settings and recognising the open page.

Install

Four steps, about two minutes

GeekRTL is not on the Chrome Web Store yet, so install it in developer mode.

  1. 1

    Download

    Get the latest version from the releases page and extract it.

  2. 2

    Extensions page

    Type this in the address bar:

    chrome://extensions
  3. 3

    Developer mode

    Turn on the Developer mode switch at the top of the page.

  4. 4

    Load it

    Click Load unpacked and choose the GeekRTL folder. Then open one of the AI chats and write in Persian.

The same steps work in Edge, where the extensions page is edge://extensions. Persian step-by-step guide: INSTALL.md
